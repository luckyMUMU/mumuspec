# Layer 2 Test Cases — 功能组件

## TC-2-001: 任务卡片渲染

- **Given**: 任务 { title: "Test", status: "todo", createdAt: "2026-08-01T00:00:00Z" }
- **Then**: TaskCard 组件渲染包含：
  - 正确标题文本
  - 正确状态标签（灰色圆点 + "Todo" 文字）
  - 创建时间（格式化为本地化日期）
  - 编辑和删除按钮

## TC-2-002: 创建任务

- **Given**: 用户填写标题 "New Task"
- **When**: 点击「创建任务」按钮
- **Then**: 
  - fetch POST /tasks 发送请求
  - 成功后新任务添加到列表顶部
  - 输入框清空

## TC-2-003: 创建任务验证失败

- **Given**: 用户未填写标题（空输入）
- **When**: 点击「创建任务」按钮
- **Then**: 输入框边框变红，显示错误提示「标题不能为空」

## TC-2-004: 编辑任务标题

- **Given**: 用户点击某任务卡片的「编辑」按钮
- **Then**: 标题变为可编辑输入框，状态变为下拉框
- **When**: 用户修改标题后点击「保存」
- **Then**: fetch PATCH /tasks/:id 发送更新请求，成功后刷新任务

## TC-2-005: 编辑任务取消

- **Given**: 用户点击某任务卡片的「编辑」按钮进入编辑态
- **When**: 用户点击「取消」按钮
- **Then**: 恢复到只读显示态，不发送任何 API 请求

## TC-2-006: 删除任务确认

- **Given**: 用户点击某任务卡片的「删除」按钮
- **Then**: 弹出确认对话框「确定要删除此任务吗？」
- **When**: 用户确认
- **Then**: fetch DELETE /tasks/:id 发送请求，成功后从列表移除

## TC-2-007: 删除任务取消

- **Given**: 用户点击删除后弹出确认对话框
- **When**: 用户点击「取消」
- **Then**: 对话框关闭，任务保持不变
