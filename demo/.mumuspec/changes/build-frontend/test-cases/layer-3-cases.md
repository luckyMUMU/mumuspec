# Layer 3 Test Cases — 交互逻辑

## TC-3-001: API 错误处理

- **Given**: API 返回 500 错误
- **When**: 用户执行创建操作
- **Then**: 显示错误提示「服务器错误，请稍后重试」，不崩溃

## TC-3-002: 网络断开处理

- **Given**: 网络连接断开
- **When**: 用户执行任何 API 操作
- **Then**: 显示错误提示「网络连接失败，请检查网络」

## TC-3-003: 加载状态

- **Given**: API 响应延迟（模拟 500ms）
- **When**: 用户触发数据刷新
- **Then**: 显示 loading 状态（按钮禁用 + 加载动画）

## TC-3-004: 筛选后排序保持

- **Given**: 用户已筛选为「done」状态
- **When**: 切换排序方式
- **Then**: 筛选条件不变，仅排序方式变化

## TC-3-005: 连续快速操作保护

- **Given**: 用户快速连续点击删除按钮两次
- **Then**: 第一次请求完成后才处理第二次，避免重复删除
