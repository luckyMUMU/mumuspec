## 模式描述

所有 API 端点返回统一的 JSON 格式：

```typescript
interface ApiResponse<T = unknown> {
  success: boolean;
  data?: T;
  error?: string;
}
```

## 使用规则

- 成功：`{ success: true, data: <result> }`
- 失败：`{ success: false, error: <message> }`
- HTTP 状态码与 success 一致（2xx = true, 4xx/5xx = false）

## 优点

- 客户端只需检查 `success` 字段即可判断请求结果
- 错误信息统一格式，便于处理
- 类型安全（使用泛型 T）
