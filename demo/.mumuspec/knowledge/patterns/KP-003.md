## 模式描述

使用模块级 `Map` 作为存储引擎，通过导出的 CRUD 函数操作数据，不直接导出 Map 实例。

## 代码示例

```typescript
// 模块级单例，不导出
const store = new Map<string, Task>();

// 导出操作函数
export function createTask(data: { title: string }): Task { ... }
export function getTask(id: string): Task | undefined { ... }
```

## 优点

- 封装存储实现细节，调用方不依赖具体存储引擎
- 未来可替换为数据库实现（只需修改函数内部逻辑）
- 避免全局变量污染

## 注意事项

- 内存存储在重启后数据丢失
- 不适合多进程/多实例部署（数据不共享）
