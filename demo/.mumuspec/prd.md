# Product Requirements: task-api

## 模块职责

task-api 是一个轻量级任务管理 REST API 服务，提供任务的创建、查询、更新和删除功能。
整个项目使用 Node.js 原生模块构建，零运行时依赖，适合作为 MumuSpec 规范驱动开发的演示项目。

项目同时包含一个图片分享子应用（image-share），支持图片上传和在线预览。

## 存在理由

- 演示 MumuSpec 规范驱动开发工作流的完整流程（Open → Design → Build → Verify → Archive）
- 展示 Ponytail 编码约束在实际项目中的应用
- 提供一个最小可工作的 REST API 示例，不依赖任何外部框架
- 验证树状分布规范、知识层、变更生命周期等核心特性

## 用户场景

### 场景 1: 创建任务

用户通过 HTTP POST 请求提交任务标题和状态，系统创建任务并返回生成的 ID 和时间戳。

### 场景 2: 查看任务列表

用户通过 GET 请求获取所有任务，系统返回完整任务列表。

### 场景 3: 更新任务状态

用户通过 PATCH 请求更新任务标题或状态，系统校验后更新并返回最新数据。

### 场景 4: 删除任务

用户通过 DELETE 请求删除指定 ID 的任务。

### 场景 5: 图片分享

用户通过图片分享子应用上传图片，生成可分享的预览链接。

## 验收标准

- AC-1: 所有 CRUD 端点正常工作，返回统一 JSON 格式 `{ success, data, error }`
- AC-2: 任务标题非空且不超过 200 字符，状态为 todo / in-progress / done 之一
- AC-3: 服务端口可通过环境变量 PORT 配置（默认 3000）
- AC-4: 服务端异常返回 500 状态码且不暴露堆栈信息
- AC-5: 非法输入返回 400 状态码和详细错误描述
- AC-6: 零运行时依赖（仅使用 Node.js 标准库）
- AC-7: 图片分享应用支持图片上传与预览
