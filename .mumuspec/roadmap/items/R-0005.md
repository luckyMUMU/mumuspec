# R-0005: Meta-Spec Evolution 框架

## 背景

> 2026 年元进化（Meta-evolution）是 AI 编程的下一个范式转移：Gödel Machine → DGM（ICLR 2026，SWE-bench 20%→50%）→ HyperAgents（Meta AI）→ AGP Autogenesis。
> MumuSpec 的 self-improve-loop 变更证明了"用自身工具改进自身规范"的可行性，需将此实践固化为正式能力。

## 依赖说明（Dependency Rationale）

- `R-0002`（Loop Auto-Evaluation）：元进化的"经验验证"基础指标来源于此（test pass rate、drift score）。没有客观的 Loop 评估，元进化无法判断"规范变更是否真的改善了产出"。
- `R-0003`（AST-based Guard）：元进化作用于 Guard Layer 的规范条目，AST 引擎提供的语义分析能力是"约束有效性评分"的技术基础。

## 范围

### 包含（Includes）
- **Enforcement 条目有效性评分** — 通过率 vs 误报率双维度评估（0.0-1.0）
- **低评分条目优化建议队列** — 低于阈值自动标记 + 生成改进建议
- **`mumuspec meta-evolve` 命令** — `--analyze`（评分报告）+ `--propose`（改进提案）+ `--apply`（安全应用）
- **`.mumuspec/contracts/meta-evolution/`** — 元进化操作契约目录（AGP RSPL/SEPL 对齐）
- **知识层元进化（R0）** — 自动调整 freshness、PageIndex、经验密度标签
- **Skill 效能驱动的自动推荐（R1）** — 基于 scope 的 Skill 组合推荐
- **所有 Meta 变更强制执行影响分析 + 用户征询流程** — Goal Preservation 保障

### 不包含（Excludes）
- 规范的自主无人确认修改（坚持人工确认门）
- 跨代差异蒸馏（R4 长期愿景）
- LLM 权重微调（不改变底层模型）

## 架构三原则

1. **分离进化对象与机制** — 规范（What）和执行机制（How）独立进化
2. **经验验证替代形式证明** — 每次规范变更通过 Loop 指标验证效果
3. **不可修改的外部锚定** — 核心 SHALL NOT 条目（Goal Preservation）不可被 meta-evolve 修改

## 验收标准（DoD）

| # | 验收条件 | 验证方法 |
|---|---------|---------|
| 1 | Enforcement 条目包含 `effectiveness_score` 字段 | 至少 10 条约束有评分 |
| 2 | 低评分条目自动进入优化建议队列 | score < 0.3 自动标记 |
| 3 | `meta-evolve --propose` 生成规范改进提案 | CLI 输出 markdown 提案 |
| 4 | Meta 变更被强制影响分析和用户确认 | Guard 拦截未分析直接 apply |
| 5 | 知识层 freshness 自动调整后引用有效 | 引用后 freshness 自动提升 |
| 6 | 基于 scope 的 Skill 推荐准确率 > 60% | 测试集评估 |
| 7 | 至少一个端到端 Meta 变更完整走通 | dogfooding（用自身工具改进自身） |
| 8 | 核心 SHALL NOT 条目不可被进化修改 | 验证 Goal Preservation 锚定生效 |

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 元进化导致意外规范退化 | 中 | 高 | 强制回滚能力 + 外部锚定 |
| 有效性评分数据不足（冷启动） | 高 | 中 | 初始人工标注 + 渐进自动化 |
| Goal Preservation 失效 | 低 | 极高 | 核心 SHALL NOT 不可修改 + 每次进化审计 |

## 互斥理由（Mutex Rationale）

> 为什么不能与 `R-0001`（Graph 编排引擎）同时进行？

R-0001 大规模重构 runtime 架构（并行调度、worktree 管理），会影响 Guard Layer 的执行集成点（如 worktree 中的规范校验如何触发）。R-0005 需要稳定的规范执行层作为进化对象。同时进行会导致"改变的基线不确定"，增大回归风险。
