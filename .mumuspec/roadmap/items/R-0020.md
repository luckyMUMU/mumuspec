# R-0020: 错误码发射面裁决

## 背景

`mumuspec conformance` 的 E2 探针扫出无发射点的注册错误码。首跑 17 项；剔除纯残留（装载面、规范文档、测试三处均无引用）6 项已删除（E-CHANGE-005、E-GUARD-007、E-PONYTAIL-003/004、E-KNOWLEDGE-002/003）。

## 裁决

保留注册位但把「无发射点」变成表内声明并受机器核对的判据：**注册表条目的 `reserved` 字段是唯一事实源**，`docs/reference/error-codes.md` 由生成器渲出「无发射点 + 现由哪条通道承担」，`mumuspec conformance` 只在没有任何语料 `mustContain` 期望该码时才判其为闭合——声明与期望矛盾即违反。声明因此不是免检通道。

| 码 | 分类 | 依据 |
|---|---|---|
| E-SPEC-005、E-SPEC-007、E-SPEC-012 | 声明保留 | 覆盖核对分属 drift / PageIndex 重建 / annotation-enforcement 通道；`.mumuspec/spec.md` 已声明其为 registered-but-not-emitted 前例 |
| E-DESIGN-001、E-DESIGN-002 | 声明保留 | 同一条件由 phase-guard 的建议级 W-DESIGN-001 / W-DESIGN-002 发射（CHG-5 过程约束降档，advisory 定位不变） |
| E-DESIGN-009 | 声明保留 | 结构缺节自 CHG-5 起为建议级 W-DESIGN-009；模板与 design-schema 已改指实际码 |
| E-GUARD-004 | 声明保留 | hash 复核由建议级 W-GUARD-004 承担（允许 Build 迭代调整测试） |
| E-CHANGE-004 | 声明保留 | 锁定后的改动由 hash 复核（W-GUARD-004 / E-CHANGE-022）事后检出，不存在写入前置门；直接编辑文件无 API 可拦截 |
| E-SECURITY-003 | 补发射点 | MCP 工具 schema 声明 required 的 path/dir 参数缺失或非字符串时返回该码与修复步骤；此前落入 `resolve(root, undefined)` 抛 Node TypeError |
| E-KNOWLEDGE-001 | 补发射点 + 档位对齐 | `organizeKnowledge` 的必填字段缺失发现挂上该码；注册表档位由 ERROR 改为 WARN，与实际告警档位一致 |
| E-PONYTAIL-002 | 撤回 | 「标准库已满足却引入新依赖」需意图判断，机械不可判定；`checkPonytail` 的依赖比对按 ponytail 注释留空。注册 ERROR 码即假强制，全仓检索零活引用后删除 |
| W-SECURITY-001 | 新增 | 敏感信息扫描落地（`src/guard/sensitive-info.ts`）：`.mumuspec/` 规范工件与 decisions.md 按固定模式集扫描，掩码摘录 + audit 记录，见 R-0021 关联机制讨论 |

引用面口径已固化在探针里：`.mumuspec/knowledge/**`（导入快照）、`.mumuspec/changes/**`（历史工件）、`.mumuspec/roadmap/**`（债务登记表——登记面若算承诺源，裁决后的条目会被自己的登记文本钉住）、`docs/appendix/**`（冻结研究）不计为承诺；`.eval-corpus` 的期望按"脱钩即违反"处理，不当承诺。

## 范围

### 包含（Includes）
- 逐码三分类裁决：①应发射但未接线（补发射点）；②能力已废弃或机械不可判定（同批撤回码与文档引用）；③条件由其它档位通道承担（表内声明保留，并由语料期望反向核对）
- 裁决结果回写：错误码文档由生成器重出，术语表与参考文档同步改指实际发射码
- 探针口径：声明保留须无语料期望，否则计为违反；advisory 清单归零后比值覆盖全部注册码

### 不包含（Excludes）
- 为让比值达标而放宽探针或把待裁决项直接计入通过
- 借裁决之机调整过程约束的 advisory 定位（CHG-5 纪律不变）

## 验收标准（DoD）

| # | 验收条件 | 验证方法 |
|---|---------|---------|
| 1 | 每个无发射点码要么有表内声明，要么已撤回 | `mumuspec conformance` E2 = 1.000 且 error-code-emitted 的 advisory 为空 |
| 2 | 文档声明的码与引擎实际发射的码一致 | 生成文档呈现「无发射点」列；glossary 与 guard-layer 引用改指实际码 |
| 3 | 声明不与语料脱钩 | 语料测试与探针同读 `DECLARED_UNEMITTED_CODES`；声明码出现在任一 `mustContain` 即为违反 |
| 4 | 无引用即无残留 | 全仓检索已撤回码零命中 |
