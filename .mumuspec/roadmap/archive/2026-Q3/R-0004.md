# R-0004: Onboarding CLI

## 背景

> 竞品（OpenSpec/Superpowers/GSD）只需复制文件夹或一个 init 命令即可使用，而 MumuSpec 新用户需要同时理解 SHALL/SHALL NOT、Ponytail、Constraint Strength、BOUNDARY.md、五阶段+Loop 双模式等 10+ 概念体系。
> 新用户完成首个变更时间约 60-120 分钟，是 OpenSpec 的 6-10 倍。

## 关键设计决策

**合并现有 `knowledge-onboard`**：当前 `knowledge-onboard` 提供"理解代码库"的学习路径，R-0004 新增"配置生成 + 首个变更引导"。合并为统一 `mumuspec onboard` 命令，避免功能碎片化。

**渐进式披露三层架构**：
1. **Quick Start**（默认）：5 问 → 生成 config → 直接开始首个变更
2. **Guided Tutorial**：完整 15 分钟交互式教程
3. **Advanced Config**：完全手动控制（原有 init 全部能力）

## 范围

### 包含（Includes）
- **`mumuspec onboard`** — 引导式问答（项目类型、团队规模、严格程度偏好）自动生成优化配置
- **三套内置模板** — frontend / backend / fullstack，每套包含预配置的最佳 Guard Layer + 适合的 constraint_strength
- **渐进式功能披露** — 新用户默认 Quick Start，高级功能通过 `mumuspec config set advanced.enabled true` 显式开启
- **`mumuspec tutorial`** — 交互式教程（15 分钟内完成首个变更全流程：init → new → design → build → verify → archive）
- **README 快速开始 ≤ 20 行** — 首屏直接展示 `npm i -g mumuspec && mumuspec onboard`

### 不包含（Excludes）
- 图形化 Web 教程（仅 CLI 交互）
- 完整的视频课程
- 框架核心逻辑的任何修改（纯 UX 优化 + 模板丰富度提升）

## 验收标准（DoD）

| # | 验收条件 | 验证方法 |
|---|---------|---------|
| 1 | `mumuspec onboard` 引导 5 问答后生成可用 config | 新用户测试：5 分钟内完成 |
| 2 | 模板包含最佳 Guard Layer 预配置 | 模板内容审查（至少 5 条 SHALL + 3 条 SHALL-NOT） |
| 3 | 高级功能默认隐藏，需显式开启 | `advanced.enabled` 默认 false |
| 4 | Tutorial 覆盖首个变更全流程（6 阶段） | 新用户测试：15 分钟内完成 |
| 5 | README 首页 quick start ≤ 20 行 | 行数验证 |
| 6 | 现有 `knowledge-onboard` 功能完整保留 | 回归测试通过 |
