## 1. 主线 A：分发层 canonical-first

### 1.1 模块与边界（自顶向下）

```
src/install/
├── installer-registry.ts    [改] AgentType + 'codex'|'windsurf'|'gemini'|'copilot'
│                                 AGENT_RULE_TARGETS（声明式规则目标表，新增）
├── installer-ops.ts         [改] 各 agent 落盘路径接线；skill 目录式分发统一
└── rules-generator.ts       [新] 纯函数渲染器：input(规则目标+规范上下文) → output(文件内容三态判定)
src/doctor.ts（或既有 doctor 模块）[改] legacy 存量检测 + 规范保护降级警告
```

- **`AGENT_RULE_TARGETS` 是规则的唯一持有处**（KP-0060"规则归 LLM/配置"）——每个 agent 声明：`{ rulesFile: 'AGENTS.md', bridges: { claude: 'CLAUDE.md', gemini?: 'GEMINI.md' }, skillsDir, marksManaged: true }`。新增 agent = 只改这张表，不改渲染逻辑。
- **`rules-generator.ts` 不做 IO**（纯函数，返回 `{ path, content, action: 'create'|'update'|'skip' }[]`），落盘由 installer-ops 执行——可测性与 BOUNDARY 清晰。

### 1.2 生成物契约
