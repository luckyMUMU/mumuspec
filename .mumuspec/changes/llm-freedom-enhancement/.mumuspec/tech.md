## Requirement: Test Coverage — workflow-recommender

### SHALL
Tests must cover:
1. `deriveRiskTier()` — low / medium / high risk classifications
2. `estimateScope()` — builds scope with correct risk_level
3. `checkSafetyFence()` — blocks on cross_module / new_public_api / new_external_dep / data_migration
4. `recommendPath()` — safety fence → full, high risk → full, doc_only → tweak, pure_bugfix → hotfix
5. `formatRecommendation()` — outputs path + confidence + rationale string

## Requirement: Test Coverage — CLI Integration

### SHALL
Tests must cover:
1. `mumuspec new name --files 1 --bugfix` → console output contains "Recommended: hotfix"
2. `mumuspec new name --files 10 --cross-module` → output contains "Recommended: full"
3. `mumuspec new name --doc-only` → output contains "Recommended: tweak"
4. proposal.md is created and contains recommendation text
5. State persists scope signals (estimated_files, cross_module, etc.)
