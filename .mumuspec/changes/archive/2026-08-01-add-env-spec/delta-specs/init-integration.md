## SHALL

在 `mumuspec init` 流程中集成环境检测，自动发现项目所需工具链并生成初始环境规范。

### 集成点

1. **项目分析阶段**：调用 `detectEnvironment()` 获取基础环境信息
2. **知识库初始化**：生成初始 KP 页面记录环境配置
3. **env-spec.md 生成**：如果项目包含构建工具配置文件（pom.xml、build.gradle、package.json），则生成对应的 `env-spec.md` 要求

### 检测触发条件

| 文件存在 | 执行检测 |
|----------|----------|
| `pom.xml` | Java + Maven |
| `build.gradle` | Java + Gradle |
| `package.json` | Node.js + 包管理器 |
| `requirements.txt` / `pyproject.toml` | Python |
| `go.mod` | Go |
| `Cargo.toml` | Rust |
