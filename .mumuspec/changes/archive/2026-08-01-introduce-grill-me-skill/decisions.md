# 决策记录

## Design 阶段

| ID | 决策 | 理由 | 日期 |
|----|------|------|------|
| D-006 | grill-me 作为 Step 2.5 而非独立步骤 | 保持 Design 阶段步骤内聚，便于 Phase Guard 检查 |
| D-007 | 事实与决策分离：Agent 自查事实性信息 | 减少用户负担，尊重用户时间（grill-me 核心原则） |
| D-008 | 上限 10 轮 + 用户随时退出 | 避免无限追问，用户自主控制 |
| D-009 | 双层确认：单问题 + 整体共识门禁 | 既保证单个决策准确，也保证全局共识 |
| D-010 | 强制冲突回退到认知框架增量轮 | grill-me 发现的深度冲突相当于认知框架的增量输入 |
| D-011 | 不新增 CLI 命令，仅修改 phase-design.md | ponytail: 最小侵入，保持 CLI 稳定 |
| D-012 | 2 层测试用例（Layer 0 根协议 + Layer 1 模块细节） | 覆盖核心协议和集成细节 |
