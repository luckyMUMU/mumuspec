# R-0003: 分布式 Spec V2 修复 — Tech Spec

## Requirement: Architecture Constraints

### SHALL
- `src/spec/parser.ts` 必须提供 `parsePrdFile` / `parseTechFile` / `serializePrdFile` / `serializeTechFile`
- `src/spec/loader.ts` 必须提供 `processInheritance` 实现 parent_prd/parent_tech 解析
- `src/spec/validator.ts` 必须对 prd.md 执行 E-SPEC-008/011、对 tech.md 执行 E-SPEC-009/011/012
- `src/core/spec-scaffolder.ts` 必须生成符合 V2 格式的 prd.md / tech.md
- `src/guard/checker.ts` 的 `checkProhibitions` 必须覆盖 prd.md / tech.md 中的 SHALL NOT
- `src/core/errors.ts` 必须包含 E-SPEC-008~012 定义

### SHALL NOT
- 不得修改 `parseSpecFile` 的函数签名或返回类型（向后兼容）
- 不得引入新的 npm 依赖
- 不得改变 `mumuspec init` 的非分布式行为（默认行为不变）

## Requirement: Distributed Spec Discovery Flow

### SHALL
```
projectRoot
├── .mumuspec/
│   ├── prd.md          ← discovered
│   ├── tech.md         ← discovered
│   ├── spec.md         ← backward compat
│   └── index.yaml
├── src/
│   ├── .mumuspec/
│   │   ├── prd.md      ← discovered (parent_prd: ../../../prd.md)
│   │   └── tech.md     ← discovered (parent_tech: ../../../tech.md)
│   └── core/
│       └── .mumuspec/
│           └── tech.md ← discovered
```

- `findAllDistributedSpecDirs()` 递归查找所有包含 .mumuspec/ 的目录
- 解析时自动解析 `parent_prd` / `parent_tech` 构建继承链
- 加载时按层级自小而下合并约束

## Requirement: Guard Layer Integration

### SHALL
- Guard checker 验证 SHALL NOT 时，除 spec.md 外还需加载 prd.md + tech.md
- 若 prd.md / tech.md 不存在则跳过（向后兼容）
- 约束提取使用现有的 `parsePrdFile` / `parseTechFile` 接口
