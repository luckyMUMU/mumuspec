# R-0003: 分布式 Spec V2 修复

## Requirement: Feature Goals

### SHALL
- 支持 prd.md / tech.md 的标准化解析（frontmatter + Requirement 块格式）
- 支持 parent_prd / parent_tech 继承关系，自动合并父级约束
- 支持分布式 spec 目录发现（findAllDistributedSpecDirs）
- Validator 必须对 prd.md / tech.md 执行 E-SPEC-008~012 校验
- Scaffooter 必须能生成符合 V2 格式的 prd.md / tech.md
- Guard Layer 必须从 prd.md / tech.md 提取 SHALL NOT 约束执行检查
- 保持向后兼容：旧格式 spec.md 不强制迁移

### SHALL NOT
- 不得破坏现有 spec.md 的解析、加载、校验流程
- 不得引入新的外部依赖（使用标准库 yaml 解析）
- 不得删除任何现有类型或函数签名

## Requirement: User Scenarios

### SHALL
- User can: 运行 `mumuspec init --distributed` 自动生成 prd.md + tech.md
- User can: 运行 `mumuspec validate` 时同时校验 prd.md + tech.md 格式
- User can: 子目录的 prd.md 通过 parent_prd 引用父目录 prd.md
- User can: Guard Layer 从 prd.md / tech.md 读取 SHALL NOT 并执行检查
- User can: 项目可以混合使用旧 spec.md 和新 prd.md/tech.md（渐进迁移）

## Requirement: Acceptance Criteria

### SHALL
- 90+ 现有 spec/ tests 全部通过
- 新增 e2e 测试覆盖 init → validate → guard 完整闭环
- 现有 mumuspec validate 命令对 prd.md / tech.md 输出正确校验结果
- 现有 mumuspec context 命令在分布式项目上能加载 prd + tech 上下文

### Enforcement
- PRD-distributed-spec-v2-1: 所有 spec/* 测试套件 still green
- PRD-distributed-spec-v2-2: 新增 e2e 测试覆盖 Guard 集成
- PRD-distributed-spec-v2-3: 实际项目 validate 输出无 false-negative
