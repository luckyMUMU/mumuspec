# Layer 5 — 图数据确定性渲染
## TC-L5-001 确定性
| 场景 | 期望 |
|---|---|
| 同一工作流连续渲染两次（同格式） | 输出字节一致 |
| 输入源顺序改变但图内容相同 | 输出字节一致（稳定序，不依赖遍历序） |
## TC-L5-002 可见性反向用例
| 场景 | 期望 |
|---|---|
| 存在无边可达的节点 | 该节点出现在输出中并带孤立标记 |
| 存在未挂阻塞点的转移边 | 该边在输出中标注为未把守 |
| 存在无上游来源的约束条目 | 渲染报出而非静默省略 |
## TC-L5-003 语义保真
| 场景 | 期望 |
|---|---|
| 回退边与正向边 | 在输出中可区分，且计数类别（回退/重建）保真 |
| 四视图各一 | 泳道含阶段×阻塞点映射；状态机含当前节点与剩余预算；约束树含层间收紧；契约图含上下游 |
## TC-L5-004 格式封闭与只读
| 场景 | 期望 |
|---|---|
| 未知格式请求 | 失败并报 E-GRAPH-002，不回落默认 |
| 渲染调用前后比对 | 不写状态工件、不触发阶段转换、git 工作树不变 |
| 源数据自相矛盾（边指向未知节点） | 失败并报 E-GRAPH-003，指出矛盾点 |
## TC-L5-005 文档图示对账
| 场景 | 期望 |
|---|---|
| 设计文档图块与投影结构不一致 | 文档审计报出该块（WARN 级，不阻断） |
| 一致 | 无告警 |
