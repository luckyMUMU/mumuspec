# Layer 2 — 架构偏好选型与 design.md 出路
## TC-L2-001 骨架渲染
| 输入 | 期望 |
|---|---|
| picks 中某议题未选定 | 该节输出显式未决标记，且被 schema 校验计为缺失 |
| picks 中议题选定且含备选与理由 | 输出含"选定 / 备选 / 理由（未选代价）"三项，缺一即渲染校验失败 |
| picks 选定但备选集合为空 | 视同缺失，校验报出该议题 |
