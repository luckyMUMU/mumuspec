# Layer 4 — Worktree 门与复用
## TC-L4-001 工作树门
| 场景 | 期望 |
|---|---|
| 隔离档位为强制且变更无工作树 | 阶段守卫阻断并报 E-GUARD-014 |
| 允许降档且无工作树 | 降为 warn，降级事后可查询、留痕含原因 |
| 关闭档 | 行为与基线一致，不产生新告警 |
## TC-L4-002 工作树创建
| 步骤 | 期望 |
|---|---|
| 进入 design 时按有效档位创建 | 工作树存在且路径由既有解析函数给出 |
| 创建失败注入 | 中断转换、记录原因、状态不出现半成品（无工作树记录却声称已建） |
| 归档与废弃 | 既有清理链路对新创建的工作树生效，槽位释放 |
## TC-L4-003 契约按范围导入
| 场景 | 期望 |
|---|---|
| 导入已注册契约 | 校验与影响分析命令可消费导入结果；审计链含来源范围 |
| 来源范围不存在 | 失败并列出可选范围，不返回空集合 |
| 来源契约已废弃 | 阻断并提示替代项 |
## TC-L4-004 约束复用带来源
| 场景 | 期望 |
|---|---|
| 按范围与需求名复用 | 条目携带来源声明并落入来源集合 |
| 缺来源声明的复用请求 | 拒绝并报 E-SPEC-018 |
| 复用将放宽本层约束 | 拒绝（只可收紧） |
## TC-L4-005 注册表文件名一致
| 场景 | 期望 |
|---|---|
| 配置声明与代码常量 | 同值；该文件缺失时命令报出而非静默通过 |
