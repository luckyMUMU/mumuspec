# Layer 6 — 声明一致率与文档对账
## TC-L6-001 三比值违反计数
| fixture | 期望 |
|---|---|
| 声明有而实现无的项 | 计入 E1 违反，比值下降 |
| 实现有而无消费者的项 | 计入 E2 违反 |
| 声称把守而无校验器的门 | 计入 E3 违反 |
| 全部闭合 | 三比值均为 1.0 |
## TC-L6-002 指标接入面
| 场景 | 期望 |
|---|---|
| 指标命令输出 | 含三比值与违反清单；不影响 check/validate 既有输出结构 |
| 收敛评估 composite | 权重之和、阈值、稳定窗口与基线逐字节一致（不受新指标影响） |
## TC-L6-003 断言双向
| 场景 | 期望 |
|---|---|
| 实际值低于声称值 | 报出（既有行为不回退） |
| 声称值低于实际值 | 同样报出（现网静默通过的缺陷） |
## TC-L6-004 语料与聚合
| 场景 | 期望 |
|---|---|
| 违反 fixture 位于规范 walker 不扫描的路径 | 命中预期码；无 expected 声明的子目录不被静默丢弃 |
| 探针启动失败或输出不可解析 | 该 fixture 不计为漏检 |
## TC-L6-005 进度文档复位
| 场景 | 期望 |
|---|---|
| 进度权威文档的机器可核断言 | 与实测一致（命令数、工具数、约束计数、strong_ratio、agent 数） |
| 概览与愿景文档的进度表述 | 引用权威文档，不各自维护数字 |
