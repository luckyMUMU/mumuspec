# Layer 3 — 减法收敛与旁路收口
## TC-L3-001 删除面无幽灵引用
| 场景 | 期望 |
|---|---|
| 全仓检索已删除能力面的类型名、子命令名、配置键、错误码 | 在 src、tests、docs、skills、.mumuspec 五处均无残留引用 |
| 命令注册表 | 被删命令不再出现在顶层与叶子清单中 |
## TC-L3-002 假承诺清零
| 场景 | 期望 |
|---|---|
| 配置声明的持久化后端选项 | 只剩实现真实存在的取值；声明与实现一致 |
| 未实现动作的用户面 | 不存在返回成功的占位路径；动作缺失即失败并给出理由 |
## TC-L3-003 provider 注册表收口
| 步骤 | 期望 |
|---|---|
| AST 检查与契约分析两处旁路改走注册表后，既有判定结果 | 与基线一致（违规集合不回退、不新增） |
| 注册表内置 provider | 数量与语言集合一致；javascript provider 不再逐字段展开复制 typescript provider |
| 未注册语言请求 | 明确失败并给出支持的集合 |
